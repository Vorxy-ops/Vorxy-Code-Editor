# Vorxy Code Editor

Профессиональная мобильная среда разработки для Android.

---

## О приложении

Vorxy Code Editor — это полнофункциональная интегрированная среда разработки (IDE) для мобильных устройств на базе Android. Приложение предоставляет возможность писать, редактировать и сохранять код на 10 языках программирования с подсветкой синтаксиса, поиском и заменой, а также форматированием кода.

Приложение разработано для программистов, студентов и всех, кто хочет иметь доступ к своему коду в любое время и в любом месте без необходимости использования настольного компьютера.

## Функциональные возможности

### Редактор кода
- Подсветка синтаксиса для 10 языков программирования
- Нумерация строк
- Поиск и замена текста
- Форматирование кода (Python, C-подобные языки)
- Отображение количества строк

### Поддерживаемые языки

### Файловый менеджер
- Создание новых файлов
- Открытие существующих файлов
- Сохранение файлов
- Переименование файлов
- Удаление файлов
- Автоматическое сохранение последнего открытого файла

### Настройки

- Настройка размера шрифта (от 12 до 24)
- Выбор размера табуляции (2 или 4 пробела)
- Автосохранение
- Выбор языка интерфейса (13 языков)
