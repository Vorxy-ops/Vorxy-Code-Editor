# Vorxy Code Editor

Мобильная среда разработки для создания, редактирования, загрузки и сохранения кода на 10 языках программирования.

---

## О приложении

Vorxy Code Editor — это мобильная среда разработки для устройств на базе Android. Приложение позволяет писать, редактировать, загружать и сохранять код на 10 языках программирования с подсветкой синтаксиса.

Приложение разработано для программистов, студентов и всех, кто хочет иметь доступ к своему коду в любое время и в любом месте.

---

## Поддерживаемые языки

- Python
- C
- C++
- Java
- C#
- JavaScript
- Visual Basic
- SQL
- R
- Rust

---

## Возможности

- Подсветка синтаксиса для 10 языков программирования
- Загрузка и сохранение файлов с устройства
- Автоопределение языка по расширению файла
- Тёмная/Светлая тема
- Многоязычный интерфейс (Русский, English)
- Управление файлами (удаление, выбор нескольких, удалить все)

- 25 МБ свободного места
