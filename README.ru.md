# Vorxy Code Editor

Мобильная среда разработки для создания и редактирования кода на 10 языках программирования.

---

## О приложении

Vorxy Code Editor — это мобильная среда разработки для устройств на базе Android. Приложение позволяет писать, редактировать и сохранять код на 10 языках программирования с подсветкой синтаксиса.

Приложение разработано для программистов, студентов и всех, кто хочет иметь доступ к своему коду в любое время и в любом месте.
